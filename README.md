# 思想文库 · 个人书籍创作收录

一个零依赖的纯静态站点，用来收录个人思想书籍：**书籍 → 章节 → 页签** 三级创作结构，像写小说一样直接落笔，内容自动保存在本机浏览器。

## 功能

- **登录页**：默认账号 `123456`，密码 `xiaoxiong666`
- **首页 · 个人思想书籍综述**：写下全部书籍的总纲，实时统计书籍 / 章节 / 页签 / 累计字数
- **＋ 添加书籍**：生成书籍方框，可命名、可上传封面照片，方框内「开始创作」进入本书
- **书籍创作页**：书籍总纲 / 前言可直接打字，下方是章节网格
- **＋ 添加章节**：章节方框可命名、可上传封面，「开始创作」进入本章
- **章节创作页**：稿纸式正文输入区，可 **＋ 添加页签**（一章多页签），页签可重命名、可删除
- **自动保存**：所有输入防抖落盘到浏览器 localStorage，关页面前也会兜底写一次
- **导出 / 导入备份**：一键把全部数据存成 JSON 文件，换设备可还原

## 目录结构

```
index.html              页面骨架（登录 / 首页 / 书籍 / 章节 四个视图）
assets/css/style.css    全部样式
assets/js/store.js      数据层：localStorage 读写、统计、图片压缩、备份
assets/js/app.js        界面层：路由、渲染、事件
```

## 本地打开

直接双击 `index.html` 即可，无需服务器、无需安装任何依赖。

## 说明

- 数据只存在**你自己的浏览器**里（localStorage），不上传任何服务器。
- 封面照片会自动压缩到最大宽 720px 的 JPEG，避免占满浏览器存储。
- 清理浏览器数据 / 换浏览器会导致内容丢失，建议定期「导出备份」。
- 登录校验在前端完成，仅用于防止他人随手翻看，不具备真正的安全防护能力。
